# Architecture Decision Records

Each ADR captures a significant architectural or technology decision, the context in which it was made, and its consequences.

## Index

| ADR | Title | Status |
|---|---|---|
| [ADR-001](ADR-001-Initial-Architecture.md) | Initial Architecture for AI Trading Ecosystem | Accepted |

## When to Write an ADR

Create a new ADR when a decision:

- Introduces a new technology or dependency.
- Changes a bounded context or service boundary.
- Alters the data flow or communication pattern.
- Impacts security, scalability, or deployability.

Use the template established in ADR-001.
